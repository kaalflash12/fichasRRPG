# fichasRRPG

Repositório de fichas para Firecast.

## Star Wars Saga

A publicação da versão 7.3.4 está em preparação. Esta versão corrige o endereço do atualizador para `kaalflash12/fichasRRPG` e mantém o importador de XML da RPGmeister 3.5.

O canal de atualização será publicado em `update.txt` junto com o RPK validado. A instalação direta continua sujeita à autorização do próprio Firecast para gerenciar plugins.

Dados e XMLs de personagens não fazem parte deste repositório.
